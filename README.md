# Probel Sleep Studio

Crie um site profissional, moderno, responsivo e de alto padrão para uma loja física autorizada da rede Probel Colchões. igual esses https://www.probel.com.br/  e com as mesmas cores

 IMPORTANTE: O site deve ser inspirado na organização, experiência de navegação e estrutura de um grande e-commerce de colchões, mas não deve copiar literalmente o site oficial da Probel. Crie uma identidade visual própria para esta unidade, mantendo uma aparência premium, confiável, confortável e alinhada ao segmento de colchões e descanso. OBJETIVO PRINCIPAL: Apresentar os produtos da loja, facilitar a busca por colchões e conjuntos, gerar contatos qualificados e direcionar o cliente para o WhatsApp para tirar dúvidas, solicitar orçamento, consultar disponibilidade ou finalizar a compra. O site deve ser pensado para conversão, tráfego pago e acesso pelo celular. IDENTIDADE VISUAL: - Visual elegante, moderno e profissional. - Utilizar azul escuro como cor principal. - Utilizar branco e tons muito claros de cinza como base. - Utilizar detalhes discretos em azul médio. - Evitar excesso de cores, gradientes exagerados e elementos genéricos. - Tipografia moderna, legível e sofisticada. - Layout limpo, com bastante espaço em branco. - Aparência de loja consolidada e confiável. - Usar imagens realistas de quartos, colchões, camas box e ambientes confortáveis. - Não utilizar imagens com aparência artificial ou excessivamente genérica. - Criar uma experiência visual premium, mas comercial. ESTRUTURA DO SITE: 1. BARRA SUPERIOR DE BENEFÍCIOS Criar uma faixa fina no topo com informações como: “Conforto e qualidade para suas melhores noites” “Atendimento especializado” “Compre pelo WhatsApp” “Entrega e montagem conforme disponibilidade” Adicionar ícones discretos. 2. CABEÇALHO Criar um cabeçalho moderno e fixo durante a rolagem. Elementos: - Logo da loja com espaço para inserir a logo oficial posteriormente. - Campo de busca com o texto: “O que você está procurando?” - Menu de navegação: Início Colchões Conjuntos Box Box Baú Cabeceiras Travesseiros Ofertas Sobre Nós Contato - Botão destacado: “Falar no WhatsApp” - Ícone de carrinho. - Menu mobile em formato hambúrguer. 3. HERO PRINCIPAL Criar um banner grande e elegante. Utilizar uma imagem realista de um quarto sofisticado, com uma cama confortável e um colchão premium. Texto principal: “Seu descanso começa aqui.” Texto complementar: “Encontre o colchão ideal para transformar suas noites em mais conforto, qualidade e bem-estar.” Botões: “Conheça os colchões” “Fale com um especialista” Adicionar uma pequena área de confiança abaixo do banner: ✓ Atendimento personalizado ✓ Produtos originais ✓ Condições especiais ✓ Compra segura 4. SEÇÃO DE CATEGORIAS Título: “Encontre o conforto ideal para você” Criar cards grandes, modernos e clicáveis para: - Colchões - Conjuntos Box - Box Baú - Cabeceiras - Travesseiros - Ofertas Cada card deve conter: - Foto realista. - Nome da categoria. - Pequena descrição. - Efeito suave ao passar o mouse. - Botão ou indicação “Ver produtos”. 5. SEÇÃO DE DESTAQUES Título: “Produtos em destaque” Criar uma vitrine com cards de produtos. Cada card deve conter: - Foto do produto. - Nome. - Categoria. - Descrição curta. - Preço anterior riscado. - Preço promocional. - Condição de pagamento. - Selo de desconto quando necessário. - Botão “Ver detalhes”. - Botão “Comprar pelo WhatsApp”. Criar inicialmente produtos fictícios apenas como estrutura, com dados fáceis de editar posteriormente. Exemplos: Colchão Probel Premium Colchão Probel Comfort Conjunto Box Probel Elegance Conjunto Box Probel Supreme Box Baú Probel Travesseiro Probel Viscoelástico Não inventar especificações técnicas oficiais. Utilizar textos genéricos até que os produtos reais sejam cadastrados. 6. BUSCA POR TAMANHO Criar uma seção visual com o título: “Qual é o tamanho ideal para você?” Criar botões ou cards: - Solteiro - Solteirão - Viúva - Casal - Queen - King Ao clicar, filtrar ou direcionar para a página correspondente. 7. SEÇÃO DE OFERTAS Criar uma área de destaque com fundo azul escuro. Título: “Ofertas especiais para você dormir melhor” Texto: “Consulte nossas condições e encontre a opção ideal para seu conforto.” Botão: “Consultar ofertas no WhatsApp” Adicionar espaço para inserir promoções futuras. 8. SEÇÃO DE BENEFÍCIOS Título: “Por que comprar com a gente?” Criar quatro cards: Atendimento especializado “Nossa equipe ajuda você a encontrar o produto ideal.” Qualidade e conforto “Produtos desenvolvidos para proporcionar melhores noites.” Compra facilitada “Consulte condições e formas de pagamento.” Suporte próximo “Conte com atendimento antes, durante e depois da compra.” 9. SEÇÃO INSTITUCIONAL Criar uma seção com foto de uma loja de colchões moderna. Título: “Mais conforto para a sua rotina” Texto: “Somos uma loja especializada em soluções para o sono e o bem-estar. Nosso objetivo é oferecer atendimento próximo, produtos de qualidade e orientação para que cada cliente encontre o colchão ideal.” Adicionar botão: “Conheça nossa loja” Criar espaço para inserir: - Nome da unidade. - Endereço. - Cidade. - Horário de funcionamento. - Fotos reais da loja. 10. DEPOIMENTOS Título: “O que nossos clientes dizem” Criar três cards com avaliações fictícias apenas como estrutura. Exibir: - Nome. - Avaliação com cinco estrelas. - Comentário. - Foto opcional. Deixar todos os dados fáceis de editar. 11. CTA FINAL Criar uma seção forte para conversão. Título: “Precisa de ajuda para escolher seu colchão?” Texto: “Fale com nossa equipe e receba um atendimento personalizado.” Botão grande: “Conversar pelo WhatsApp” O botão deve abrir uma conversa com mensagem pré-preenchida: “Olá! Vim pelo site e gostaria de receber ajuda para escolher um colchão.” 12. RODAPÉ Criar um rodapé completo com: Logo da loja. Links: Institucional Sobre nós Produtos Ofertas Contato Política de privacidade Trocas e devoluções Perguntas frequentes Informações: Endereço Telefone WhatsApp E-mail Horário de atendimento Adicionar ícones de: Instagram Facebook WhatsApp Adicionar aviso: “Imagens meramente ilustrativas. Consulte disponibilidade, preços e condições diretamente com nossa equipe.” 13. PÁGINAS INTERNAS Criar as seguintes páginas: /colchoes /conjuntos-box /box-bau /cabeceiras /travesseiros /ofertas /sobre /contato Cada página de categoria deve ter: - Banner. - Título. - Descrição. - Filtros. - Grade de produtos. - Botão de WhatsApp em cada produto. 14. PÁGINA DE PRODUTO Criar uma página completa com: - Galeria de imagens. - Nome do produto. - Preço. - Condição de pagamento. - Descrição. - Características. - Tamanhos disponíveis. - Botão “Solicitar orçamento”. - Botão “Comprar pelo WhatsApp”. - Produtos relacionados. O botão do WhatsApp deve enviar automaticamente o nome do produto na mensagem. Exemplo: “Olá! Tenho interesse no produto [NOME DO PRODUTO] e gostaria de receber mais informações.” 15. FUNCIONALIDADES Implementar: - Design totalmente responsivo. - Excelente experiência no celular. - Menu mobile. - Busca de produtos. - Filtros por categoria e tamanho. - Carrinho visual. - Botão flutuante de WhatsApp. - Botões de conversão bem destacados. - Animações suaves e discretas. - Carregamento rápido. - SEO básico. - URLs amigáveis. - Estrutura preparada para Google Analytics. - Estrutura preparada para Meta Pixel. - Eventos de conversão para: ViewContent Search AddToCart InitiateCheckout Contact Lead Criar uma área administrativa simples ou uma estrutura de dados que permita adicionar, editar, ocultar e organizar produtos facilmente. IMPORTANTE: - Não utilizar textos longos ou genéricos. - Não criar informações oficiais sem confirmação. - Não inventar garantias, tecnologias ou condições comerciais. - Deixar preços, produtos, endereço, WhatsApp e informações da loja fáceis de editar. - Criar componentes reutilizáveis. - Utilizar boas práticas de UX/UI. - Priorizar conversão pelo WhatsApp. - O resultado deve parecer um site profissional de uma grande loja de colchões, e não um template genérico.
